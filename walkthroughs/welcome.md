# Bem-vindo ao OpenBase

O OpenBase CLI é sua ferramenta de produtividade para projetos .NET. Aqui estão os passos para começar:

### 1. Criar novo projeto
Use o comando `OpenBase: New Project` para gerar a estrutura base.

### 2. Scaffold de Entidade
Use o comando `OpenBase: Scaffold` para criar o CRUD completo.

### 3. Rodar aplicação
Use o comando `OpenBase: Run` para iniciar o projeto.

Acesse a documentação completa no GitHub para mais detalhes.
